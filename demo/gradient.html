How the threshold maps onto a gradient

  • Per-pixel alpha: the library draws the image to an off-screen canvas and reads the alpha channel under the cursor.
  • The rule: alpha > threshold → pointer-events: auto (clickable); otherwise pointer-events: none (click-through).
  • On a gradient alpha changes smoothly, so the threshold acts like a movable cut line: it slides the opaque/transparent boundary along the fade in real time.
  • Proof of click-through: a button sits behind each gradient. Click the solid part and the gradient catches it; click the faded part and the click reaches the button beneath.
